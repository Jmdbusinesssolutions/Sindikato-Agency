# Sindikato Agency — Website

An ultra-modern, high-performance, and editorial luxury agency website built for **Sindikato Agency**, inspired by the design architecture, typography, and interactive benchmarks of [tequila.ae](https://tequila.ae/).

---

## 🌟 Key Features & Design Architecture

### 1. **Visual Tone & Theme System**
- **Signature Dark Mode & Crisp Light Mode**: Dynamic theme switcher with `localStorage` persistence.
- **Editorial Typography**: Pairing high-impact bold sans-serif with bespoke editorial serif italics (`Instrument Serif`) and monospaced technical tags (`JetBrains Mono`).
- **Color Accent**: Electric Lime (`#CCFF00`) and Neon Cyan highlights over deep obsidian charcoal surfaces.
- **Glassmorphism & Micro-Interactions**: Ambient glowing backgrounds, card borders with gradient highlights, magnetic interactive cursor follower for desktop.

### 2. **Core Sections & Modules**
1. **Glassmorphism Header & Mega-Menu**: Dropdown navigation across disciplines, theme switch button, and magnetic *Let's Talk* CTA.
2. **Hero Section**:
   - Location indicator (`MANILA • DUBAI • GLOBAL CREATIVE STUDIO`).
   - Editorial headline with serif highlights.
   - **AI Quick Brief Bar**: Transmits client brief directly into contact inquiries.
   - **Real-Time Animated Counter Metrics**: (16+ Years, 420+ Brands Built, 99.4% Client Retention, 54 Awards).
3. **Showreel Interactive Canvas**: Dynamic 60FPS particle grid background with sound simulation & video trigger.
4. **Infinite Client Ticker Marquee**: Smooth continuous brand marquee.
5. **The Three Disciplines (Pillars)**:
   - **01 / The Web & Tech** (Next.js 15, WebGL 3D, Headless E-Commerce, UI/UX Systems).
   - **02 / The Brand** (Brand Strategy, Visual Identity, Bespoke Typography, Elevation).
   - **03 / The Noise & Media** (Cinema Film, Stage Visuals, Artist Management, Viral Campaigns).
6. **Curated Case Studies & Portfolio Grid**:
   - Interactive category filter tabs (All, The Web, The Brand, The Noise & Media).
   - Interactive modal walkthrough with problem, solution, metrics, and technology stack.
7. **Interactive Project Scope & Cost Estimator**:
   - Real-time interactive calculation based on discipline, tier, and velocity with 1-click booking synchronization.
8. **Why Sindikato (4 Core Distinctions)**: Dual-hub velocity, Silicon Valley code + Milan craft, 100% IP transfer, and multi-million dollar ROI.
9. **Industries We Dominate**: Real Estate & Architecture, Fintech & Web3, Luxury & Lifestyle, F&B, Music & Live Entertainment, Enterprise SaaS.
10. **Global Awards & Honors**: Awwwards SOTD, DesignRush Top Agency, Clutch Global, PentaAwards, Webby Honors.
11. **Verified 5.0 Testimonials Carousel**: Rotating client reviews with live star ratings.
12. **Interactive FAQ Accordion**: Clear breakdown of timelines, IP ownership, and workflow.
13. **Thought Leadership Insights**: Editorial articles on modern design, WebGL performance, and virality.
14. **Global Contact Hub & World Clocks**:
    - Live real-time clocks for Manila, Dubai, Singapore, and London.
    - Multi-step project inquiry form with validation and instant toast feedback.

## 🚀 How to Run Locally

You can run a local preview server using Python or Node.js:

```bash
# Using Python
python3 -m http.server 8000

# Or using Node.js npx serve
npx serve .
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
